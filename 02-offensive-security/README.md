# 02 — Offensive Security

This section documents authorized offensive-security learning and practical methodology.

## Tracks

- Reconnaissance
- Enumeration
- Web application security
- Vulnerability validation
- Initial access
- Privilege escalation
- Post-exploitation concepts
- Penetration-testing methodology
- Risk and remediation reporting

## Methodology

**Scope → Recon → Enumeration → Validation → Exploitation → Privilege escalation → Evidence → Remediation → Report**

All testing is performed only against systems and environments where authorization exists.

## Certification connection

The immediate certification target is **eJPT**. Practical labs are used as the readiness gate rather than treating the certification as a substitute for hands-on capability.
