# 07 — Digital Forensics & Incident Response

DFIR is a long-term specialization built on strong operating-system, networking, and blue-team fundamentals.

## Learning path

1. Windows artifacts
2. Event logs
3. Filesystem and application artifacts
4. Evidence handling and integrity
5. Timeline construction
6. Basic incident investigation
7. Memory and disk-forensics concepts
8. Dedicated forensic labs

## Investigation principle

Preserve evidence, establish a timeline, validate observations, document assumptions, and separate facts from hypotheses.
