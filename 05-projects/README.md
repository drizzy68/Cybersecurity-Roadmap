# 05 — Projects & Security Evidence

This directory is the portfolio layer of the roadmap. Projects should demonstrate applied capability rather than simply list topics studied.

## Evidence standard

A strong artifact should show:

- Objective and scope
- Environment or assumptions
- Methodology
- Commands/tools or implementation
- Observations and evidence
- Findings or outcome
- Troubleshooting
- Security relevance
- Remediation or lessons learned

## Current project themes

- Authorized network enumeration
- Web application security analysis
- Penetration-testing methodology and reporting
- VMware/virtualization documentation
- Security automation with Python
- Future SOC investigations and detection projects

## Public-safety rule

Never publish passwords, tokens, private credentials, sensitive production topology, private IP mappings that should not be public, or other confidential internship/client information.
