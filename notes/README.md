# 📝 Learning Notes

`notes/` is the personal, chronological learning journal for this repository.

## Purpose

Notes capture:

- what I studied that day
- questions I encountered
- mistakes and troubleshooting
- commands I want to remember
- ideas for future labs
- reflections on progress

## What does not belong here

Do not turn dated notes into duplicate textbook chapters.

If a concept becomes important enough to be permanent reference material, move the explanation to its canonical topic under:

- `01-foundations/`
- `02-offensive-security/`
- `03-blue-team/`
- `07-dfir/`

The dated note should then link to the canonical explanation.
