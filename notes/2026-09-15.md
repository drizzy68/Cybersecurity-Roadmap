## What changed in my understanding

### Shell parsing

A filename can look like an option. Prefixing a path with `./` or using appropriate quoting changes how the shell/program receives the argument.

### `find`

The important lesson was not one command. It was learning to combine predicates for:

- path
- type
- size
- ownership
- permissions

### stdout and stderr

`2>/dev/null` demonstrated that normal output and diagnostic output are separate streams. Suppressing expected permission errors can make a broad search usable while preserving actual results.

### Pipelines

Small utilities can be composed:

```text
sort → uniq
strings → grep
```

Each command has a focused job and the pipeline creates a larger operation.

### Content versus filename

`file` demonstrated why security analysis should identify content from actual file characteristics rather than trusting names or extensions.
