# 🧪 Labs

This directory is reserved for standalone lab material that does not belong to a specific portfolio project or CTF track.

## Lab standard

Each lab should state:

- objective
- authorization/scope
- prerequisites
- topology/environment
- setup
- task
- observations
- troubleshooting
- result
- cleanup
- transferable lesson

If a lab becomes a polished portfolio artifact, move or reproduce the final evidence under `05-projects/` rather than maintaining two competing versions.

Canonical conceptual material belongs in the relevant learning section. The lab should link to it instead of copying it.
