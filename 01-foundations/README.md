The foundation layer builds the operating knowledge required before advanced security work becomes reliable.

## Core domains

- Networking — IPv4, subnetting, CIDR, TCP/IP, ports, protocols, routing, VLANs, DNS, DHCP
- Linux — shell, filesystem, permissions, processes, services, networking, troubleshooting
- Windows — administration, services, Event Viewer, PowerShell, authentication, Active Directory fundamentals
- Python — scripting, parsing, automation, APIs, networking, security tooling
