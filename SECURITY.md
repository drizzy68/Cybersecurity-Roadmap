# Security Policy

## Scope

This repository is a public cybersecurity learning portfolio. It may contain security tooling, educational examples, lab notes and sanitized assessment evidence.

## Sensitive information

Do not open an issue or pull request containing:

- passwords
- API keys
- access tokens
- private keys
- confidential client data
- private infrastructure details
- personal information

If sensitive information is accidentally committed, treat it as compromised: revoke or rotate the secret and remove it from repository history as appropriate.

## Vulnerabilities in this repository

If you identify a security issue in code contained here, provide a minimal reproduction and avoid including secrets or unnecessary exploit material in a public issue.

Where private reporting is available, use the repository's private vulnerability reporting mechanism.

## Responsible-use principle

Security techniques documented here are intended for systems I own, controlled training environments, CTF platforms, or explicitly authorized assessments.
