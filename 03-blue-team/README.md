# 03 — Blue Team / SOC

The blue-team track supports the primary employability direction of this roadmap: junior SOC / security operations capability.

## Tracks

- Windows and Linux security logs
- Event Viewer and PowerShell
- SIEM fundamentals
- Detection and alert triage
- Authentication and access events
- Incident-response workflow
- Timeline construction
- Basic threat intelligence
- Security monitoring and reporting

## Investigation model

**Alert → Validate → Scope → Investigate → Correlate → Contain/Escalate → Document → Improve detection**

## Next practical focus

Start with Windows Event Viewer, authentication events, PowerShell fundamentals, and basic log-investigation exercises before moving into heavier SIEM labs.
